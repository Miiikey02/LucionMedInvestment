# 医药赛道研究库 · Agent guide

Structured data from 《医药全产业链细分赛道筛选与头部企业研究报告》 (author 杨诚, data as of 2026-11-17), plus a weekly feed of post-report events. Everything is static JSON under `site/api/`, generated by `tools/rebuild.sh`.

## Where to read it

| How | Address |
|---|---|
| Local files | `site/api/*.json` in this folder |
| Local server (`.claude/launch.json` → `yiyao-saidao`) | `http://localhost:8765/api/index.json` |
| Published site (GitHub Pages or another host) | `https://<site>/api/index.json` and the other files below |
| CLI | `python3 tools/query.py <keyword>` · `--company 名称` · `--route 名称` · `--track 名称` · `--pos 重点跟踪` · `--updates 14` · `--base http://localhost:8765` |

## Endpoints

| File | Contents | Key fields |
|---|---|---|
| `api/index.json` | metadata, counts, endpoint list, `updates_last_run` | |

| `api/routes.json` | 64 技术路线 | `rank, name, direction, group, track, score, pos(重点跟踪/主动看项目/保持观察/暂不投入), scenario_scores (top 20 only, else null), targets[], analysis[], update_ids[]` |

| `api/updates.json` | weekly post-report events | `last_run, items[{id, date, type, entity_type(company/route/track), entity, title, summary, source_name, source_url, evidence(A/B/C), found_at}]` |

## Conventions to keep in answers

- `（推断）` in text marks the report author's inference. Keep it when quoting.
- 证据等级 A to D: A regulator filings and peer review, B company announcements and authoritative media, C trade media and databases, D company self-reported claims.
- Updates never change the report's scores or positioning. Present them as post-report events.
- Not investment advice.

## AI 研究助手与外部 API 端口

The assistant runs in the browser. Each question goes through a tool loop: the page sends `{system, messages, tools}` to the AI gateway (`gateway/gateway.mjs`, `POST /chat`), runs any tool calls the model returns, and sends the results back, for up to 7 rounds. The gateway holds every API key. The model can be any OpenAI-compatible provider, or Claude through the Anthropic API; `LLM_PROVIDER`, `LLM_BASE_URL` and `LLM_MODEL` select it. `config.json` → `ai_gateway_url` tells the page where the gateway is; when it is empty, the assistant shows a not-configured notice and the rest of the site works unchanged.

Tools are defined in `TOOLS` in `tools/template.html`:
- library: `search_library`, `get_track`, `get_route`, `get_company`, `list_overview`, `list_updates`
- called directly from the browser (CORS-enabled public APIs): `clinicaltrials_search`, `clinicaltrials_detail` (ClinicalTrials.gov API v2), `chembl_molecule_search`, `chembl_target_search`, `chembl_mechanism` (ChEMBL REST)
- through the gateway: `web_search` (`POST /search`, Bocha or Tavily, shown only when configured), `read_webpage` (`POST /fetch`, public http/https only)

To plug in another API:
1. If the API is public and allows cross-origin requests, add an entry to `TOOLS` whose `run` calls it with `fetch`.
2. If it needs a key or blocks cross-origin requests, add a route in `gateway/gateway.mjs` that calls it with a key from the environment, then add a `TOOLS` entry whose `run` calls `gw('/your-route', ...)`. Set `needs` on the entry if the tool should appear only when the gateway reports the feature.
3. Run `./tools/deploy.sh`, and redeploy the gateway if you changed it.

## Weekly update

The scheduled task `lucion-saidao-weekly` follows `UPDATE_TASK.md`, appends verified events to `data/updates.json`, advances `data/pipelines.json`, and runs `tools/deploy.sh`, which rebuilds the site and pushes it to GitHub when a remote is set. To refresh the report itself, replace `source/report.docx` with the new version (same structure) and run `tools/deploy.sh`.
